
# Smart AI Complaint Routing Agent

An AI-powered complaint management system that automatically analyzes and routes university complaints to the appropriate departments.

## Features

- Supports Bangla, English, and Banglish complaints
- AI-based complaint classification
- Automatic department routing
- Priority detection (Low, Medium, High)
- Complaint ID generation
- Complaint history
- Admin login and dashboard
- Search and filter complaints
- Update complaint status
- Dashboard statistics

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Groq AI
- Supabase
- Git and GitHub
- Visual Studio Code

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Create a `.env` file and configure your API keys and database credentials.
5. Run the application:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

## Project Purpose

The purpose of this project is to make university complaint management faster and more efficient using Artificial Intelligence.
